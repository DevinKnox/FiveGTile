# 5G 快捷开关

基于 LSPosed / Xposed，为系统控制中心添加独立的 **5G 开关**

## 功能

- **一键切换**：轻点开启或关闭默认上网卡的 5G
- **状态同步**：显示开启、关闭、切换中等状态，响应默认上网卡、SIM 卡和飞行模式变化
- **设置入口**：长按开关进入设置，或点击首页「进入5G页面」
- **操作反馈**：回读系统设置确认切换结果，失败时提示；飞行模式、无默认上网卡时不可切换，锁屏时先解锁
- **浅深主题**：首页跟随系统主题，动态显示设备型号与 Android 版本

「已开启」表示允许使用 5G，实际连接取决于运营商、套餐和信号覆盖

## 使用

前提：设备已 Root，并安装 LSPosed 或兼容框架

1. 安装模块 APK
2. 在 LSPosed 启用模块，作用域勾选「系统界面」`com.android.systemui`
3. 重启手机
4. 在控制中心编辑页面添加「5G」开关；ColorOS 设备安装后先打开应用，也可点击「添加5G开关」直接添加

未出现开关时，检查模块和作用域，并在 LSPosed 日志搜索 `[FiveGTile]`

## 适配

| 设备 | 系统 |
| --- | --- |
| 小米 13（`fuxi`） | MIUI 14 / Android 14 |
| 一加 PLK110（`OP60FFL1`） | ColorOS 16 / Android 16，固件 `16.0.0.208(CN01)` |

ColorOS 使用 Android 标准快捷开关服务，5G 操作由 SystemUI 中的 Hook 执行；小米保留原有控制中心实现。切换功能与首页进入 5G 页面都需要模块已加载到系统界面。一加适配尚待真机功能验证
